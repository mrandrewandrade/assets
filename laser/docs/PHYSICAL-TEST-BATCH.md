# First physical test batch

Software validation confirms file structure and intended dimensions; it does not prove fit, strength, cut settings, flame behaviour, or safe load capacity.

Record the material species, supplier, nominal thickness, caliper readings at several locations, machine, lens, focus method, power, speed, frequency/PPI, air assist, measured kerf, operator, and date.

## Batch A — calibration and dimensions

- Dimension verification sheet and 100 mm ruler check
- 50 mm circle and 50 mm circular hole
- 100 × 200 mm plate and square/diagonal check
- Kerf comb
- Material-thickness gauge
- Slot-fit, tab-fit, and hole-fit gauges
- Loose/slip/snug/press fit series

## Batch B — assemblies

- One 100 × 150 mm French-cleat module backer
- One module cleat, lower standoff, anti-slide stop, and anti-lift retainer
- One removable generic holder module
- One easel or cross stand
- One tab-and-slot joint and one cross-lap joint

## Acceptance record

For each file, record actual X/Y dimensions, diagonal, slot/hole dimensions, selected fit, assembly result, edge quality, failure mode, changes, and the next verification state. Change `review_status` only with recorded evidence:

- `dimension-tested`: measured feature dimensions recorded
- `fit-tested`: mating-feature results recorded for a specified material/machine
- `shop-tested`: used safely in the intended shop context, including load and retention checks

French-cleat and pegboard adapters are prototypes. Thin laser-cut plywood must not be treated as structural support for heavy or hazardous tools. Use appropriate solid rails, fasteners, backing, and load testing approved for the wall and tool mass.
